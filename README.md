# 🏠 ЖЕКА І САША: ХАТА НА ДВОХ
### …і месть Єгору 💪

Жека і Саша пробують прожить разом 7 днів у хаті Дениса, не посваритись,
накачаться і побить трьох босів: **Дениса**, **Єгора** і (секретно) **Севу-доксера**.

Шутки: 0% смішні, 100% навоз. 🥁 *ба-дум-тсс*

## Як запустить

Скачай файли (зелена кнопка **Code → Download ZIP**), розпакуй і відкрий `index.html`
в браузері (Chrome / Edge / Firefox). Більше нічо ставить не нада.

## Режими

| Режим | Шо треба |
|---|---|
| 🎮 **Вдвох за одною клавою** | нічо, просто відкрить `index.html` |
| 🙋 **Одному (Саша — бот)** | нічо. Бот варить, працює, прибирає, виганяє Дениса, дає п'ять і б'ється з босами |
| 🌐 **Онлайн по коду** | інтернет. Один нажимає «Створить кімнату» і каже другу 5 цифр, другий вводить код |
| 🖧 **Онлайн через Radmin VPN / LAN** | Radmin VPN (або одна Wi-Fi сєть) і `hata-server.exe` |

### Як грать через Radmin VPN

1. Обидва ставите [Radmin VPN](https://www.radmin-vpn.com/) і заходите в одну сєть.
2. Хост запускає `hata-server.exe` (лежить поруч з грою).
   - Windows може сказать «Система Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**.
   - Коли спитає про брандмауер — **Разрешить доступ** (галочки на обидві сєті).
3. У хоста сам відкриється браузер з грою (`http://localhost:8777`).
   Друг відкриває `http://<IP хоста в Radmin>:8777` — IP видно в Radmin VPN і у вікні сервера (починається на `26.`).
4. В меню обидва вибирають **«Онлайн через Radmin VPN / LAN»**: хост — «Створить гру», друг — «Підключиться до хоста».

Не закривайте вікно сервера, поки граєте.

## Управління

| | Жека | Саша |
|---|---|---|
| Ходить | `W` `A` `S` `D` | Стрілки |
| Дія | `F` (або `E`) | `Enter` (або `Num0`) |
| Кинуть / показать біцепс | `G` (або `Q`) | `/` (на укр. розкладці це «.») |
| Ривок | `Пробіл` (або `R`) | `.` (на укр. розкладці це «Ю») |

Одному і онлайн — працюють **всі** кнопки, грай як зручно. Геймпади тоже робе.
`Esc` — пауза, `M` — звук, `Backspace` на паузі — вийти в меню.

## Шо робить в хаті

- 🥟 **Їжа:** холодильник → плита → забрать → з'їсти. Не забрав — згоріло.
- 💻 **Комп:** долби дію — капають гроші. В 23:00 Денис бере аренду.
- 🏋️ **Штанга і груша:** долби дію — росте сила. Сила = урон по босах.
- 💩 **Навоз:** на склад = патрони на босів, до дверей = продать за 20₴.
- ❤️ **Дружба:** диван вдвох, «дай п'ять», їжа і чистота. Впаде до нуля — роз'їдетесь (але можна помириться і переграть день).
- 📋 **Квести:** 3 штуки кожен день, за них гроші і дружба.
- 🛒 **Магазин між днями:** скороварка, робот-пилосос, протеїн, перчатки, аптечки…
- Події: 🚪 Денис, 🕵️ Сева у вікні (зливає компромат на Єгора), 🚚 доставка навозу,
  🪳 таргани, 🌊 потоп, 💡 світло вирубили, 🔔 кур'єр, 👀 Єгор підглядає.
- Жека — шеф-повар (варить бистріше), Саша — качок (качається бистріше).

## Боси

- **Денис-колектор** (після 3-го дня): квитанції, ключі-бумеранг, мусорний дощ, таран.
- **Єгор** (після 7-го дня): таран, присяд-землетрус, гантелі, а в кінці — протеїновий коктейль (збийте його!).
- **Сева-доксер** (секрет): ховається за фаєрволом — ламайте роутери, ухиляйтесь від доксінгу.

Гра зберігається на початку кожного дня (в режимах на одному компі).

## Для розробників

- Вся гра — один файл `index.html` (canvas + Web Audio, без бібліотек).
- `peerjs.min.js` — [PeerJS](https://peerjs.com) 1.5.5 (MIT) для онлайну по коду.
- `server/` — сервер на Go для Radmin VPN / LAN. Зібрать `hata-server.exe`: `cd server && ./build.sh`.
