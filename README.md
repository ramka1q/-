# 🟣 НІКІТА: Пожирач планети

Аркадна гра у стилі **Tasty Planet**: ти керуєш істотою на ім'я **Нікіта**,
що їсть геть усе й невпинно росте — від мікроба в пробірці до цілого космосу.
А група вчених намагається його зупинити.

> Уся графіка та персонажі **намальовані прямо в коді** (Canvas 2D) —
> жодних зовнішніх картинок не потрібно.

## ▶️ Як запустити

Просто відкрий `nikita-game.html` у браузері. Або підніми локальний сервер:

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000/nikita-game.html
```

## 🎮 Керування

| Дія | Клавіші |
|-----|---------|
| Рух | миша (істота пливе за курсором) або **WASD** / стрілки |
| Далі в коміксі | **клік** або **Пробіл** |
| Пауза | **P** |
| Звук вкл/викл | **M** |

**Мета:** їж усе, що менше за тебе, рости — і коли станеш достатньо великим,
проковтни боса-вченого наприкінці рівня.

## 🧪 Сюжет і персонажі

Вчені інституту створили «ідеальний організм» Нікіту — і він втік. Тепер вони
по черзі намагаються його зупинити:

1. **Лабораторія** → бос **Єгор**
2. **Кабінет вчених** → бос **Даня**
3. **Вулиця міста** → бос **Пилипюк**
4. **Мегаполіс** → бос **Діма**
5. **Над континентом** → бос **Кирило** (і його няня **Наташа**)
6. **Космос (фінал)** → головний бос, геній **Молгелевич** — він стріляє
   анти-матерією, що зменшує Нікіту!

Між рівнями — **анімовані комікси** з репліками, звуковими словами та ефектами.

## 🖼️ Фото Нікіти (необов'язково)

Поклади своє фото у `assets/nikita.png` — і воно стане обличчям монстра.
Деталі — у `assets/README.md`.

## 🗂️ Структура

```
nikita-game.html  точка входу (відкрий цей файл)
css/style.css     оформлення вікна
js/utils.js       математика, easing, помічники
js/art.js         вся графіка: Нікіта, вчені, "їжа"
js/levels.js      6 рівнів
js/comics.js      рушій анімованих коміксів
js/story.js       сценарії коміксів + намальовані фони
js/game.js        ігровий рушій (цикл, камера, поїдання, боси, звук)
```
