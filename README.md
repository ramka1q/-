# 🟣 НІКІТА: Пожирач планети

Аркада у стилі **Tasty Planet**: ти керуєш істотою на ім'я **Нікіта**, що їсть
геть усе й невпинно росте — від бактерії в крові до пожирача прибульців.
**15 рівнів, у кожного своя механіка.** Ціла спільнота вчених, армія та
прибульці намагаються його спинити. Фінальний бос — геній **Давід**.

> Уся графіка та персонажі **намальовані прямо в коді** (Canvas 2D).
> Жодних зовнішніх картинок не потрібно.

## ▶️ Як запустити

Відкрий `nikita-game.html` у браузері. Або підніми локальний сервер:

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000/nikita-game.html
```

## 📱 На телефоні (PWA — як справжній застосунок)

Гра — це **PWA**: її можна встановити на телефон і грати офлайн.

1. Відкрий `nikita-game.html` у браузері телефона (через локальний сервер або хостинг).
2. Меню браузера → **«Додати на головний екран»** (Android: Chrome; iPhone: Safari → «Поділитися» → «На екран Додому»).
3. Запускай з іконки як звичайну гру. Працює навіть без інтернету (service worker кешує файли).

Керування на телефоні: **тягни пальцем** — Нікіта пливе за пальцем; кнопка **⚡** (правий нижній кут) — ривок.

## 🎮 Керування

| Дія | Клавіші / дотик |
|-----|-----------------|
| Рух | миша / **WASD** / стрілки / палець |
| **Ривок (швидкість)** | **Shift** / **ПКМ** / кнопка ⚡ |
| Далі в коміксі | клік / **Пробіл** |
| Вибір складності | **◀ ▶** + Пробіл / клік |
| Пауза | **P** |
| Звук | **M** |

**Мета:** їж усе, що менше за тебе, рости — і коли станеш достатньо великим,
проковтни боса рівня. Ривок витрачає **витривалість** (синя смуга) — ним
ухиляйся від снарядів і пробивай щити.

## ⚙️ Складність

Перед грою обери: **ЛЕГКО / НОРМАЛЬНО / СКЛАДНО** — впливає на швидкість росту,
агресію ворогів, частоту пострілів і силу зменшення.

## 🧪 15 рівнів — 15 механік

| # | Рівень | Механіка | Бос |
|---|--------|----------|-----|
| 1 | Кровотік | бактерії **розмножуються** | Супербактерія |
| 2 | Вірусна зона | віруси **полюють** і кусають | Вірус-Альфа |
| 3 | Чашка Петрі | **течія** зносить усе | Спора-Гігант |
| 4 | Темна підлога | **темрява** (видно лише навколо) | Пацюк |
| 5 | Втеча з будівлі | прогризай **стіни** назовні | Охоронець |
| 6 | Лабораторія | асистенти **кидають колби** | Єгор |
| 7 | Кабінет | **слизька** підлога (інерція) | Даня |
| 8 | Вулиця | **трафік** — авто збивають | Пилипюк |
| 9 | Район у тумані | **туман** (стрілка до боса) | Діма |
| 10 | Місто | Наташа тримає **щит** | Кирило + Наташа |
| 11 | Дах інституту | **гравітаційні** колодязі | Молгелевич |
| 12 | Знищ квартал | **пожирай будинки** + турелі | Хмарочос-Колос |
| 13 | Армія | **танки** й важкі снаряди | Левіафан |
| 14 | Вторгнення | прибульці **телепортуються**, промінь матки | Матка прибульців |
| 15 | ФІНАЛ | щит + викликаний **робот-охоронець** | **Давід** |

Зʼївши Давіда, Нікіта стає **розумнішим і швидшим**. Між рівнями — **анімовані
комікси** з репліками, звуковими словами та ефектами.

## 🖼️ Фото Нікіти (необов'язково)

Поклади своє фото у `assets/nikita.png` — воно стане обличчям монстра.
Деталі — у `assets/README.md`.

## 🗂️ Структура

```
nikita-game.html   точка входу (відкрий цей файл)
manifest.json      PWA-маніфест (встановлення на телефон)
sw.js              service worker (офлайн-кеш)
css/style.css      оформлення вікна
js/utils.js        математика, easing, помічники
js/art.js          вся графіка: Нікіта, люди, істоти, техніка, "їжа"
js/levels.js       15 рівнів + складності
js/comics.js       рушій анімованих коміксів
js/story.js        сценарії коміксів + намальовані фони
js/game.js         ігровий рушій (цикл, камера, механіки, боси, звук)
assets/            іконки PWA + (опц.) nikita.png
```
