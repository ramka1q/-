# Сюда кладём фото Никиты

Положи фотографию Никиты в эту папку с именем:

- `nikita.jpg` (или `nikita.png`, `nikita.jpeg`, `nikita.webp`)

Игра сама найдёт файл и вырежет круглое лицо для слизня-Никиты,
для Никиты-человека в комиксах, для иконки на шкале размера и т.д.

Лучше всего подходит фото, где лицо крупно и по центру (как на аватарке).
Если лицо получилось не по центру — в игре открой **«📷 Фото»** в главном меню:
там фото можно двигать мышкой/пальцем и приближать колёсиком или кнопками `+` / `−`.

Там же можно просто загрузить фото с компьютера или телефона без всяких папок —
оно сохранится в браузере.
