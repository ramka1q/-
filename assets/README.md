# Папка assets

## Фото Нікіти (необов'язково)

Поклади сюди файл з назвою **`nikita.png`** — і це фото стане «обличчям»
монстра Нікіти прямо в грі (і в коміксах, і під час гри).

- Назва файлу строго: `nikita.png`
- Найкраще квадратне фото (наприклад 512×512), обличчя по центру
- Якщо файлу немає — Нікіта малюється повністю в коді (фіолетовий монстр-блоб),
  гра працює як завжди

Шлях: `assets/nikita.png`
