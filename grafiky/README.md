# Варіант №4 — Побудувати графіки функцій

1) y = (2/5)x − 3 — пряма, точки (0; −3), (5; −1), (−5; −5), перетин з Ox (7,5; 0). → `1.png`
2) y = −2x² + x − 3 = −2(x − ¼)² − 2⅞: а) y = −2x²; б) зсув на ¼ вправо і на 2⅞ вниз. Вершина (¼; −2⅞). → `2.png`
3) y = 3 − 4/(x + 5): а) y = −4/x; б) зсув на 5 вліво і на 3 вгору. Асимптоти x = −5, y = 3. → `3.png`
4) y = −5/3·|3x − 2| + 2 = −5|x − ⅔| + 2: а) y = −5|x|; б) зсув на ⅔ вправо і на 2 вгору. Вершина (⅔; 2). → `4.png`
5) y = −x² + |x| − 4: а) y = −x² + x − 4 при x ≥ 0 (вершина (½; −3¾)); б) відображаємо симетрично відносно Oy. → `5.png`
