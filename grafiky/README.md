# Варіант №4 — Побудувати графіки функцій

Кожен графік будується одним малюнком: ключові точки (вершина / асимптоти) + таблиця значень.

1) y = (2/5)x − 3 — пряма. Точки (0; −3), (5; −1), (−5; −5). → `1.png`
2) y = −2x² + x − 3 — парабола, вітки вниз. Вершина x₀ = −b/2a = 0,25; y₀ = −2,875. → `2.png`
3) y = 3 − 4/(x + 5) — гіпербола. Асимптоти x = −5, y = 3. → `3.png`
4) y = −5/3·|3x − 2| + 2 — «галочка» вершиною вгору. Вершина (⅔; 2). → `4.png`
5) y = −x² + |x| − 4 — дві вершини (±0,5; −3,75). → `5.png`
