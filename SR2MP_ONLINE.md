# SR2MP: игра по сети с другом бесплатно

У SR2MP нет отдельного сервера: один игрок **хостит** прямо из игры, второй подключается к нему **по IP**.
Чтобы это работало через интернет без проброса портов и без платного сервера, нужна бесплатная виртуальная локальная сеть (VPN).
Мод сам поддерживает Radmin VPN и Hamachi.

## 0. Проверь перед стартом (иначе не подключится)

- [ ] У обоих **одна и та же версия Slime Rancher 2**. Старые сборки SR2MP работают только на старых версиях игры (например, сборка для 0.4.0 на более новых не запускается).
- [ ] У обоих **одна и та же версия SR2MP** и тот же загрузчик модов (MelonLoader или BepInEx — смотри, какой нужен твоей сборке).
- [ ] Мод реально загружается: при запуске игры видно консоль загрузчика, в меню есть пункт мультиплеера.

## 1. Самый быстрый способ: Radmin VPN (бесплатно, без регистрации)

1. Оба качают и ставят **Radmin VPN** с radmin-vpn.com.
2. Хост: `Сеть → Создать сеть`, придумывает имя и пароль.
3. Друг: `Сеть → Присоединиться к сети`, вводит те же имя и пароль.
4. В Radmin у хоста рядом с его именем указан IP вида `26.x.x.x` — его нужно скопировать.
5. Хост запускает игру, загружает сейв и включает хостинг в меню SR2MP.
6. Друг в меню SR2MP вводит **`26.x.x.x` хоста** (и порт, если мод его спрашивает — порт берётся из настроек мода у хоста) и подключается.

## 2. Если Radmin не работает: ZeroTier или Tailscale

Принцип тот же: оба заходят в одну виртуальную сеть, друг подключается к IP хоста внутри неё.

- **ZeroTier** (zerotier.com): хост создаёт сеть в веб-панели, оба вводят её Network ID в клиенте, хост ставит галочку `Auth` на устройстве друга. Подключаться нужно к IP хоста вида `10.x` / `172.x` из панели.
- **Tailscale** (tailscale.com): оба входят в один аккаунт (или хост делится своей машиной с другом), подключаться нужно к IP хоста вида `100.x.x.x`.

## 3. Если не подключается

1. **Брандмауэр Windows** у хоста: при первом запуске хостинга нажми «Разрешить доступ» для частных **и** общественных сетей. Если окно не появилось: `Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением` → разреши `SlimeRancher2.exe`.
2. Проверь саму VPN-сеть: друг открывает `cmd` и пишет `ping 26.x.x.x` (IP хоста). Если пинга нет, проблема в VPN, а не в моде.
3. Подключайтесь именно к **VPN-IP** (26.x / 100.x / ZeroTier), а не к обычному IP из 2ip.ru.
4. Ещё раз сверьте версии игры и мода у обоих (пункт 0).
5. Антивирус иногда режет загрузчик модов, поэтому добавь папку игры в исключения.

## Альтернатива без VPN: проброс порта

Если роутер позволяет, хост может пробросить порт мода (TCP и UDP) на свой ПК, а друг подключится к внешнему IP хоста.
Это сложнее, и у многих провайдеров (CGNAT) просто не работает, поэтому лучше VPN из пунктов 1–2.
